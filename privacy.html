MyMemory プライバシーポリシー

制定日: 2026年11月20日 / 改定日: 2026年11月22日

本ポリシーは、iPhone と Apple Watch で動作するアプリ「MyMemory」(以下「本アプリ」) が扱う情報について説明するものです。

1. 本アプリが扱う情報

本アプリは、利用者が Apple Watch で録音した音声、その音声から作成した文字起こしと要約、録音の日時と長さ、録音時の電池残量を扱います。

2. 保存場所

音声、文字起こし、要約は、利用者の iPhone 内に保存します。これらは、利用者の設定に応じて端末のバックアップ (iCloud またはコンピュータ) に含まれます。開発者のサーバーへ送信することはありません。文字起こしと要約は、初期設定では端末内の機能で行います。要約の内容の見直しも端末内の機能で行い、外部へは送信しません。

3. 外部への送信 (任意)

利用者が設定画面で送信を許可し、かつ自身の API キーを登録した場合に限り、文字起こしのテキストを、利用者が設定画面で選んだ送信先 (Anthropic、OpenAI、Google の Gemini API、Ollama Cloud のいずれか 1 つ) の API へ送信して要約します。送信するのは、設定の「要約に使う」で外部 API を選んだとき、録音の詳細画面などで要約のたびに外部 API を選んだとき、または端末内で要約できないときです。外部 API を選んで保存すると、まだ要約の無い過去の録音の文字起こしも順に送信します。API キーを保存する前に、接続を確かめるため、確認用の短い定型文 (文字起こしは含みません) と選んだモデル名を送信先へ送ります。モデルの一覧を取得するときは、API キーだけを送ります。送信先を変えると許可は取り消され、改めて許可するまで送信しません。音声は送信しません。この送信は初期設定では無効になっており、いつでも設定画面で無効にできます。送信されたテキストの扱いは、選んだ送信先の事業者の利用規約とプライバシーポリシーに従います。

4. 第三者への提供

前項の場合を除き、本アプリが扱う情報を第三者へ提供することはありません。広告や行動追跡のための情報収集も行いません。

5. 削除

録音は本アプリの画面からいつでも削除できます。設定により、文字起こし済みの古い音声を自動で削除することもできます。本アプリを削除すると、端末内の録音、文字起こし、要約が削除されます。登録した API キーは端末の Keychain に残る場合があるため、不要になった場合は削除前に設定画面で消去してください。

6. 録音にあたってのお願い

他の人との会話を録音する場合は、相手の同意を得てください。録音が禁止されている場所では使用しないでください。
